# Remotion Prompt Bank

## Prompt: Full reel graphics series (3D hook, mixed formats, every frame moving)

Use when a creator's script needs the whole set of motion graphics: one graphic per script part, built in the creator's style.

Fill in the `[BRACKETS]` before sending.

---

**Make the motion graphics for [CREATOR]'s [PRODUCT] script in [CREATOR]'s style.**

- **Hook:** 9:8, 3D, with real depth (use the Depth prompt: perspective, depth of field, parallax). Put the hook overlay text on this first graphic: plain white text with no box behind it, small (about 38px on a 1080x960 frame), dead center, on screen from the first frame for about two seconds.
- **The rest:** mix 9:8 and 9:16, one graphic per script part. Keep each 9:16 at 8 seconds or less.
- **CTA:** nothing. No graphic for the call to action.
- **Visually stimulating:** every frame has something going on. No dead frames and no frozen holds: while one thing settles, something else is still moving (the camera drifts, a cursor types, a layer is still animating, the background moves slowly).
- **Smooth transitions:** every change between beats is a smooth eased move (camera travel, a push in, a match move from one screen to the next). No hard jumps, no linear motion, no bounce.
- **Real things on screen:** real product UI and real outputs, never labels or stamps that narrate the line.
- Give me 5 hook ideas (each with its overlay text) first, and I'll pick one. Start building the other parts while I choose.

---

What each part does:
- **3D hook with an overlay:** the depth makes the first frame look expensive, and the overlay states the hook for people watching on mute.
- **Mixed 9:8 and 9:16:** the 9:8 graphics sit above the talking head, and the 9:16 ones take over the full screen to reset attention.
- **Every frame moving:** a frozen frame is where people swipe away. There should always be at least one thing in motion.
- **Smooth transitions:** eased camera moves carry the eye from one beat to the next, so the graphic reads as one shot instead of a slideshow.

Short version: **"3D hook with an overlay, mix 9:8 and 9:16, nothing on the CTA, every frame moving, smooth transitions."**
