# Remotion Prompt Bank

Reusable prompts for briefing a Remotion graphics build. Fill in the `[BRACKETS]` before sending.

| Prompt | Use when |
|---|---|
| [Depth](depth.md) | A graphic feels flat and should read as a real 3D space (perspective, depth of field, parallax). |
| [Full reel graphics series](full-reel-series.md) | A creator's script needs the whole set: 3D hook with overlay, mixed 9:8 and 9:16, nothing on the CTA, every frame moving, smooth transitions. |
| [Screen-recording walkthrough series](screen-recording-walkthrough.md) | Sponsored graphics that look like a live screen recording of an AI agent using the product, reusing an existing creator theme. |
